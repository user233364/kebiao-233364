# 我的时间表

2026 秋课程与个人日程，支持周次切换、任意时间的自定义日程、离线查看，可安装为 PWA。

## 使用

浏览器打开 `index.html` 即可（也可直接当本地文件打开）。

- 顶部 `第 N 周 ◀ ▶` 切换周次，默认第 5 周
- **添加日程**：支持「按节次」和「自定义时间」两种方式
- 点任意课程卡片 → 查看详情 / 编辑 / 删除
- 右上角菜单 → 导出备份 / 导入备份 / 恢复出厂数据 / 打印

## 手机上安装成 App

用 Chrome 打开本页面 → 右上角 `⋮` → **安装应用 / 添加到主屏幕**。
安装后为全屏独立窗口，断网也能打开。

## 数据存放在哪

课程数据保存在**你的浏览器本地**（localStorage），不会上传到任何服务器。

- 换设备或清理浏览器数据前，请先在菜单里**导出备份**
- 站点更新不会覆盖你本地的修改；想同步仓库里的最新课表，用「恢复出厂数据」（会丢弃本机修改）

## 技术说明

- 单页应用，无外部依赖、无追踪、无后端
- `sw.js` 采用「网络优先 + 离线回退」，保证每次打开拿到最新版本
- `manifest.json` 提供图标与 standalone 显示模式
